# 株式会社 蒼建 — TUMIKI Web. portfolio

既存のプロジェクトルートに作成した、依存ライブラリ不要の静的サイトです。TOPを重点制作し、下層は概要のみを実装しています。会社・代表者・実績等はすべて創作です。

## 確認方法

`index.html` を直接開くか、プロジェクトルートで `node preview.cjs` を実行して http://127.0.0.1:4173 を開きます。ローカルサーバーは127.0.0.1のみで待ち受けます。

## 編集

- `build-pages.cjs`：文章と共通ヘッダー・フッターを管理。編集後に `node build-pages.cjs` で6ページを再生成します。
- `assets/css/style.css`：共通デザイントークン、各セクション、800px / 560pxを中心とするレスポンシブ指定。
- `assets/js/main.js`：モバイルメニュー、Escape、フォーカス循環、背景のinert、画像未配置時の表示。
- `assets/images/favicon.svg`：蒼建の仮ブランドマーク。
- `IMAGE-GUIDE.md`：画像制作・差し替え仕様。

直接HTMLを編集した場合、再生成時には上書きされます。共通部品を一元管理しつつ、閲覧時にはJavaScriptに頼らず本文・ナビ・フッターを表示します。外部フォント・CDNへの接続はありません。

## 今回の範囲と次工程

TOP → デザイン確認 → 画像制作と差し替え → SERVICE → WORKS → COMPANY → RECRUIT → CONTACT → 最終調整。

お問い合わせページはダミー番号（000-0000-0000 / tel:00000000000）と、送信・保存を行わないデモフォームを備えます。contact-demo.cjsでUIを管理し、JavaScript無効時は入力不可、CSPでもフォーム送信を禁止しています。下層の詳細設計、実績カテゴリの絞り込みや個別詳細、募集要項、会社案内の詳細は今後の制作範囲です。詳細住所・実際の連絡先・建設業許可番号は掲載しません。新規ページもbuild-pages.cjsのpage関数を使用し、共通注意書きとポートフォリオ用メタデータを継承してください。

画像差し替え後のコントラスト・トリミング、正式な公開URL、canonical / OGP画像、検索掲載方針、各下層の内容を確定してください。実績として公開する際も、フッターの架空企業の明示を維持します。
